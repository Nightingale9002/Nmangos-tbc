## 一、双阵营圣印互通（进行中）

> 需求：让联盟/部落圣骑士都能学到对方阵营的圣印（参照 TBC 怀旧服官方改动）。
> 两种圣印：31892 鲜血圣印（原部落）、31801 复仇圣印（原联盟），客户端 Spell.dbc 原生都有，**无需客户端技能表改动**。

### 1. 方案演进（重要，别走回头路）

- **方案一（训练师，已做但放弃）**：训练师模板加对方圣印 + 服务器 SkillLineAbility.dbc racemask 清 0。
  - 服务器端已验证 100% 正常：SendTrainerList 对联盟圣骑士发送 31892 fit=1（SEALDBG 日志实测 entry=5148 race=0x1 class=0x2 lvl=81）。
  - **客户端拦截**：TBC 客户端训练师窗口用**客户端自己的 SkillLineAbility.dbc** 判"阵营专属"（isFactionSpecific），
    客户端里 31892 racemask=512（仅血精灵）、31801 racemask=1029（仅联盟），跨阵营在训练师里**不可学**，无视服务器状态字节。
  - 客户端修复需改客户端 SkillLineAbility.dbc 并打 MPQ 补丁 → **253 客户端用 CASC 不吃 MPQ 补丁，不可行**；2.4.3 主服也卡在补丁加载。→ 放弃训练师路线。

- **方案二（当前，任务线学习）**：纯服务器端任务线，完成时授予技能，**完全绕开客户端训练师判定**，2.4.3 与 253 都适用。技能书显示正常（31892/31801 客户端原生）。

### 2. 本 fork 任务"学会技能"机制（关键，踩坑记录）

- **语义（用户确认）**：RewSpell = **任务让角色学会的法术**（写进技能书的那个）；RewSpellCast = **对玩家释放一次的法术**。
- **本 fork SPELL_EFFECT_LEARN_SPELL = 36**（不是标准的 53！见 src/game/Spells/SpellEffectDefines.h:62）。
- 学会发生在"释放载体法术"时：Spell::EffectLearnSpell 读 **EffectTriggerSpell**（SpellEffects.cpp）→ player->learnSpell。
- 任务奖励流程（Player.cpp RewardQuest，~13516 行）：
  - spellId = RewSpellCast; if (!spellId) spellId = RewSpell; 然后对玩家 CastSpell(spellId, TRIGGERED_OLD_TRIGGERED)
  - 即：有 RewSpellCast 就释放 RewSpellCast（载体）；没有才退而释放 RewSpell。
- **正确设计（方案 A）**：RewSpell = 31892/31801（学会的圣印本体，客户端原生显示"你学会了"）；RewSpellCast = 91010/91011（载体，Effect1=36 + EffectTriggerSpell1=圣印），释放一次触发学会。
- 骑术示例：RewSpell=33388（学会的骑术）、RewSpellCast=33389（载体，Effect1=36+Trigger=33388）→ 施放 33389 学会 33388。
- 库内另一变体（种族技能任务）：RewSpell=19338（载体本身带 36 效果）、RewSpellCast=0 → 退而释放 RewSpell，学会其 EffectTriggerSpell=13908。此变体把载体放 RewSpell，奖励图标显示 19338（客户端 DBC 存在所以正常）；自定义载体放 RewSpell 则图标"未知"→ 所以圣印任务用方案 A（载体放 RewSpellCast）。
- TRIGGERED_OLD_TRIGGERED 施放**不发客户端动画** → 载体法术对客户端完全不可见，无显示瑕疵。

### 2.1 实测结论（2026-08-21 凌晨，用户实测确认）

- **测试 1（RewSpell 单独放圣印）**：任务 91003 RewSpell=31892、RewSpellCast=0 → 交任务后**只给玩家上了一个圣印 buff（约 30 秒），技能书没有学会**。
  - 用户曾主张"RewSpell 单独即可学会"，实测否定——RewSpell 单独放真实法术（APPLY_AURA 类）只会被"施放"，不会学会。
- **测试 2（RewSpellCast 载体）**：RewSpell=31892 + RewSpellCast=91010（复制 19338 结构的载体，Effect1=36+EffectTriggerSpell1=31892）→ **测试通过，正确学会鲜血圣印**。
- **最终确认方案 A**：RewSpell=圣印本体 + RewSpellCast=载体（91010/91011），载体纯服务端不可见。
- 载体法术已建：91010（学 31892）、91011（学 31801），均复制 19338 完整结构仅改 EffectTriggerSpell 与名字。
