## 五、附：当时是怎么比对出来的

```powershell
python dev\tools\dbc_diff.py <A.dbc> <B.dbc> [打印条数]   # 逐条比对（记录数差异 + 字段级差异）
python _agent_tmp\dbc_dump.py <file.dbc> <id> ...        # 打印某条记录的全部字段（字符串块自动解码）
```
云端的 3 处补丁发现过程：逐文件 md5 全量比对 → 3 个文件不同 → 逐条 diff 定位到具体记录/字段；
再结合库表反查用途（`npc_vendor` 谁用 ExtendedCost 2049、哪个 creature 用 display 22596、
`spell_template` 里 31801/31892 是什么），才确认了每条补丁的真实作用。
