## 0. 一句话概述

玩家 **1 级**起，在**本族新手村的自己职业的训练师**处可以接到任务 **「捷径」**。
交付即**进入快档**：经验总倍率 **×2.5**（永久、不可撤销、不可取消、死亡不掉、buff 栏不可见）。
**不接这个任务就是慢档**（经验 ×1，即现状）。
慢档角色 **70 级**可在**影月谷**（联盟 20511 伊尔萨·枪酒 ／ 部落 20500 欧尔洛克）接到 **「按部就班」**：
**大师级骑术 ＋ 标准 280% 飞行坐骑四选一**。快档角色**接不到也看不到**该任务。
**整套功能＝纯数据（零代码）**，应用 dev SQL ＋ **重启一次**即可（新法术必须重启才加载）。

## 1. 规则（站长已确认）

| 项 | 规则 |
|---|---|
| 慢档 | 经验 1×（现状，**不需要任何操作**，就是"没接任务"） |
| 快档 | 经验**总 ×3**（与 `Rate.XP.*` 相乘；本服各 `Rate.XP.*`＝1） |
| 选择方式 | **完成「捷径」任务即进入快档**（`Method=0` 自动完成型任务，接到后即可交付） |
| 可逆性 | **不可逆**（快档标记一旦置位永久有效；不提供反悔/回收） |
| 快档额外奖励 | 无 |
| 慢档满级奖励 | 70 级 + **未进入快档** ⇒ 影月谷领取：**大师级骑术 + 280% 飞行坐骑四选一** |
| 入口（本轮） | **只做阶段 1：新手村职业训练师**（46 个 entry，1 级可接，见 §3.5） |
| 老角色 | ⚠️ 本轮**覆盖不到**（新手村入口对他们不现实）；阶段 2/3 做完才覆盖（见 §6-1） |
| 满级掉 buff | **不做**（70 级后 2.5× 本就无效）⇒ **零 C++** |
| buff 可见性 | **不可见**（自定义法术 id，客户端 `Spell.dbc` 无此条目 ⇒ 客户端根本不渲染） |
| 任务A 分职业 | **每职业一条任务**（共 9 条），避免"别的职业也能从别人训练师处接到" |

## 2. 技术机制（均已核实，附证据）

### 2.1 经验倍率：现成光环，零代码
- `SPELL_AURA_MOD_XP_PCT = 200`（`Spells/SpellAuraDefines.h:337`；`SpellAuras.cpp:263` 注册为 `HandleNoImmediateEffect`，注释 "implemented in Player::GiveXP"）
- **被读取**：`Entities/Player.cpp:2760-2763` → `xp = uint32(xp * (1.0f + m_amount / 100.0f))`
- 数值 = `EffectBasePoints + EffectBaseDice`（`Server/DBCStructure.h:1024` `CalculateSimpleValue`）⇒ **总 ×3 ⇒ `EffectBasePoints = 199`（配 `EffectBaseDice = 1`）**
- 干净模板：**46668**（本库唯一"只带 aura200、无副作用"）✓（不要抄 33377 另有 aura79、24705 另有 aura156、32172 另有 aura190）

### 2.2 覆盖全部经验来源：`Player::GiveXP` 是唯一漏斗
杀怪（单人 `Unit.cpp:1264`→`Player.cpp:20845`；组队 `Group.cpp:1521`）、任务（`Player.cpp:13503→13506`）、探索（`:6605/6615/6619→6622`）**全部经过 `Player::GiveXP`**；
`Rate.XP.*` 的乘法在其之前（`Maps/Map.cpp:1370-1420`）⇒ 与光环倍率**相乘** ✓。宠物经验（`Pet.cpp:1139`→`GivePetXP`）不经此处，本设计不覆盖 ✓。
⚠️ 任务完成弹窗显示的是**乘倍率之前**的经验（`Player.cpp:13551`→`14816-14833`），纯显示问题，不改 ✓。

### 2.3 快档标记 = 隐藏 flag 任务 90350（**不是光环**）
```
法术 900001 Effect1 = 16 (SPELL_EFFECT_QUEST_COMPLETE)
        TargetA1 = 1 (TARGET_UNIT_CASTER，SpellTargetDefines.h:25)
        MiscValue1 = 90350
  → Spell::EffectQuestComplete（SpellEffects.cpp:7635-7642）
  → Player::AreaExploredOrEventHappens（Player.cpp:14326）
  → Player::CanCompleteQuest：对 QUEST_FLAGS_AUTO_REWARDED 的任务**不要求它在日志里**
     （Player.cpp:13110-13113）⇒ 直接置 m_rewarded
```
- 隐藏 flag 任务 = `QuestFlags |= 0x400 (AUTO_REWARDED)`（`QuestDef.h:146`）+ `SpecialFlags = 2 (EXPLORATION_OR_EVENT，QuestDef.h:158 注释里就写了"spell SPELL_EFFECT_QUEST_COMPLETE casting")` + `Method = 0`
- 本库现成同类任务：9378 / 9713 / 9926 / 10454 / 11518 / 11577 / **11874**（本设计逐字对齐 11874）
- **为什么不用光环本身当标记**：光环一旦被任何原因移除，"没有快档标记"的判定会重新为真，互斥当场失效。
- **标记与光环放进同一个法术的两个 effect 槽**（同款先例 46711：一个法术里两个 QUEST_COMPLETE）。

### 2.4 慢档门禁：条件系统
- 反向位 `CONDITION_FLAG_REVERSE_RESULT = 0x1`（`Globals/Conditions.h:87`，取反于 `Conditions.cpp:128-129`，DB 列 `conditions.flags`）
- **"某任务未奖励" = `type=8 (QUESTREWARDED)` + `value1=任务id` + `flags=1`**（`Conditions.cpp:222-225` → `GetQuestRewardStatus`）✓
- **"等级 ≥70" = `type=15 (LEVEL)`，`value1=70`、`value2=1`**（`Conditions.cpp:259-269`：value2 `0=等于 / 1=≥ / 2=≤`）✓
- 组合 `type=-1 (AND)`：`value1..value4` 四个槽都能用；**被引用条件 id 必须更小**（`Conditions.cpp:640-667`）✓
- 挂载 `quest_template.RequiredCondition` → `Player::SatisfyQuestCondition`（`Player.cpp:13750-13762`），在 `CanSeeStartQuest:13051 / CanTakeQuest:13072 / CanAddQuest:13113` 三处检查 ⇒ **不满足时接不到也看不到** ✓

### 2.5 大师级骑术：`RewSpellCast = 34093`
- 骑术＝技能 **762**。两级法术分工（本轮实测）：
  - `34091 Riding` 是**给训练师用的**：`Effect1 = 3 (DUMMY)` + `Effect2 = 118 (SPELL_EFFECT_SKILL)`，而 `Spell::EffectSkill` 是空实现（`SpellEffects.cpp:8183-8186`）⇒ **直接 cast 它没用**。
  - `34093 Artisan Riding` 才是**能直接 cast 的**：`Effect1 = 36 (LEARN_SPELL → 34091，客户端图标)` + **`Effect2 = 44 (SKILL_STEP)`**，
    `EffectMiscValue2 = 762`、`EffectBasePoints2 = 3` 配 `EffectBaseDice2 = 1` ⇒ `damage = 4` ⇒ `Spell::EffectLearnSkill`（`SpellEffects.cpp:4752-4768`）→ `SetSkillStep(762, 4)` = **大师级**。
- 写法：**`RewSpell = 34091`（图标）+ `RewSpellCast = 34093`（实发）**；`RewardQuest` 只会施放一个（`Player.cpp:13581-13583` 先取 RewSpellCast）。
- 本服 dev/002 已有同款：90100-90109 = `33388 / 33389`（初级）、90200-90209 = `33391 / 33392`（中级）⇒ 34091/34093 是同一族的下一档。

### 2.6 经验光环的"钉死"属性（已在 dev/131 里落实）
| 目的 | 设置 | 依据 |
|---|---|---|
| 不可右键取消 | `Attributes \|= 0x80000000`（`SPELL_ATTR_NO_AURA_CANCEL`） | `Spells/SpellDefines.h:61` |
| **死亡不掉** | `AttributesEx3 \|= 0x00100000`（`ALLOW_AURA_WHILE_DEAD`） | `SpellDefines.h:158`；**46668 没有这一位，直接抄会每次跑尸丢 buff** |
| 不可驱散 | `Dispel = 0` | 同族模板均 0 |
| 无限时长/离线不消耗 | `DurationIndex = 21` | `GetSpellDuration` 返回 -1 |
| 不被打断 | `AuraInterruptFlags = 0`、`ChannelInterruptFlags = 0` | 受伤/移动/坐骑/进战斗都不掉 |
| 变形不掉 | `Stances = 0` | `IsRemovedOnShapeshiftLost`（`SpellAuras.cpp:7617-7645`） |
| 客户端无痕 | `Attributes \|= 0x00000080`（`DO_NOT_DISPLAY`） | `SpellDefines.h:37`；对未知法术无实际影响，写上表意更清楚 |

### 2.7 生效方式
`spell_template` **没有 reload 命令**（`Chat/Level3.cpp` 只有 spell_affect/area/chain/elixir/learn_spell 等）⇒ **新法术必须重启**；
`conditions` / `quest_template` / `creature_questrelation` / `creature_involvedrelation` 随重启一并生效。

## 5. 与其它方案对比（为什么这么选）

| 备选 | 不采用原因 |
|---|---|
| **凭证物品 + 确认任务（v3）** | 物品不能右键（见开头第 4 条），只能靠 `ReqItemId` 再交一次任务 ⇒ 绕一圈，收益不大 ✗ |
| **凭证物品右键使用（v2）** | 🔴 客户端 `Spell.dbc` 不认识自定义法术 ⇒ `GetItemSpell()` 返回 nil ⇒ **右键静默无反应** ✗ |
| 快档标记 = 2.5× 光环本身 | 光环一旦被移除，"没有快档标记"的判定会重新为真，互斥失效 ✗ |
| 用 46668 当光环法术本体 | 它是客户端已知法术，**客户端会画出 buff 图标**（站长要"不可见"）；且 BP=9 只有 +10% ⇒ 自己造 900001 更好 |
| `playercreateinfo_item` 建号发物品 | 不是任务；表无主键（重复行＝重复发）；`race/class=0` **不是通配**（需 52 行枚举）；**不覆盖老角色** ✗ |
| gossip 对话二选一 | 机制可行且零代码；但要给领袖/训练师加 gossip（改 `NpcFlags`）或另摆一批 NPC ⇒ 改动面更大，备选 |
| 单条任务挂多训练师 | 跨职业可接 ✗（站长否掉） |
| 满级自动掉 buff（3+3 行 C++） | 站长认为没必要（70 级后无效）⇒ 零代码 |
| `spell_area`+condition 自动上/下 buff | 移除分支只在 `RewardQuest` 的 `onlyApply=false`（`SpellMgr.cpp:2956-2967`）⇒ 做不到自动摘 |
| 稀有/绝版坐骑当奖励 | 站长改为"标准 280% 坐骑四色"；且 13335/19902/19872/32768/35513/32458 **本服全在副本掉落中** |
